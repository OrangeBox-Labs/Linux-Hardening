# Mapa versionado de referencias CIS para el verificador OrangeBox

**Revisado el:** 2026-10-26  
**Alcance:** catalogación de la referencia oficial por distribución y major version para cis-benchmark-check.sh.

> Este archivo no declara que el verificador tenga cobertura completa. El script implementa un subconjunto local de controles y debe considerarse una evaluación operacional parcial hasta que cada recomendación de la versión oficial se mapee y valide.
